Good to know

        
Questions

      

      

        

          Is it really free? Do I need an API key?
          
Yes, and no. Tinker runs on Groq's free tier through a shared key, so you can start right away. The free tier has per-minute limits; if you hit them often, add your own free Groq key under Customize to get your own limits.

        

        

          Can the terminal agent mess up my files?
          
It only works inside the folder where you started it, shows the exact changes before saving, and asks before every write or command. If you say no, nothing changes.

        

        

          Where are my chats stored?
          
In your browser for now. Sign-in with synced chats is coming. Share links contain the chat itself, so anyone with the link can read it.

        

        

          Which connectors need which model?
          
Web search and Run code use Groq's built-in tools and work with the GPT-OSS models. Web pages, GitHub and MCP servers work with GPT-OSS and Qwen.
